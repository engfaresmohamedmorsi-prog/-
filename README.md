# جوة الحكاية

تطبيق عربي لإرسال الرسائل مع موافقة واضحة، لوحة خاصة وأرشيف قابل للبحث، مساحة تأمل ذاتي غير تشخيصية، روابط التواصل، وضع ليلي، وإمكانية تثبيت الموقع كتطبيق هاتف.

تنتقل روابط الصفحة الرئيسية والتأمل الذاتي ولوحة الإدارة بين صفحات التطبيق. يعمل الموقع بالوضع الليلي تلقائيًا دون زر للتبديل إلى الوضع النهاري.

## التشغيل المحلي

يتطلب Node.js 18 أو أحدث. من مجلد هذا المشروع شغّل:

```powershell
$env:ADMIN_PASSWORD = "ضع-كلمة-مرور-طويلة-هنا"
npm start
```

اختر كلمة مرور طويلة لا تقل عن 12 حرفًا. افتح `http://127.0.0.1:4173` لإرسال رسالة، و`http://127.0.0.1:4173/dashboard` لإدارة الرسائل. مساحة التأمل الذاتي على `http://127.0.0.1:4173/self-check` لا تحفظ إجاباتك.

## النشر والرابط القابل للمشاركة

GitHub Pages يستضيف ملفات ثابتة ولا يشغّل هذا الخادم أو يحفظ صندوق الرسائل. انشر المشروع على استضافة Node.js تدعم HTTPS وتخزينًا دائمًا؛ يتضمن هذا المشروع إعدادًا مبدئيًا لـ Render في `render.yaml`.

1. أنشئ مستودع GitHub (يفضّل خاصًا) وانشر **محتويات هذا المجلد** فيه. لا ترفع ملفات `data/` أو `.env` أو `node_modules/`.
2. في Render اختر إنشاء Blueprint جديدًا، واربط مستودع GitHub. سيقرأ `render.yaml` إعداد الخدمة والقرص الدائم. إعداد القرص الدائم قد يتطلب خطة مدفوعة؛ راجع الأسعار الحالية للمزوّد قبل النشر.
3. أضف القيم السرية في إعدادات Render، لا في ملفات المستودع:
   - `ADMIN_PASSWORD`: كلمة مرور جديدة قوية لا تقل عن 12 حرفًا.
   - `VAPID_PUBLIC_KEY` و`VAPID_PRIVATE_KEY`: أنشئهما محليًا بعد تثبيت الحزم:

     ```powershell
     node -e "console.log(JSON.stringify(require('web-push').generateVAPIDKeys(), null, 2))"
     ```

     انسخ `publicKey` و`privateKey` إلى المتغيرين المقابلين في Render. لا تشارك المفتاح الخاص ولا تضعه في GitHub.
   - `VAPID_SUBJECT`: وسيلة تواصل للمشغّل بصيغة مثل `mailto:your-email@example.com`.
4. بعد نجاح النشر، افتح عنوان HTTPS الذي يعطيه Render، ثم سجّل الدخول إلى `/dashboard` واسمح بالإشعارات من جهازك. يرسل الخادم إشعارًا عامًا عند وصول رسالة، حتى إن كانت اللوحة مغلقة، طالما خدمة Node والقرص الدائم يعملان ويدعم المتصفح Web Push.
5. شارك عنوان HTTPS العام من زر «مشاركة الرابط»، أو افتحه في الهاتف واختر «تثبيت التطبيق»/«إضافة إلى الشاشة الرئيسية». رابط `127.0.0.1` هو معاينة محلية ولا يعمل للآخرين.

يمكن تثبيت الموقع من Chromium/Android. دعم تثبيت PWA وإشعارات Push يختلف حسب الجهاز والمتصفح؛ على iPhone تتطلب إشعارات الويب عادة إضافة الموقع إلى الشاشة الرئيسية وإصدار iOS مدعومًا. لا تُرسل الإشعارات إذا لم تُهيأ مفاتيح VAPID أو لم يسمح بها المستخدم.

## التخزين والخصوصية

- تُحفظ الرسائل في `data/messages.json`، واشتراكات إشعارات الإدارة في `data/push-subscriptions.json` ضمن `DATA_DIR`. على الاستضافة، اربط `DATA_DIR` بقرص دائم وقيّد الوصول إلى النسخ الاحتياطية.
- لا يحفظ التطبيق عنوان IP أو اسم المرسل أو بريده مع الرسالة. يُستخدم عنوان الاتصال مؤقتًا في الذاكرة للحد من الإرسال ومحاولات الدخول، ولا يُكتب إلى ملف الرسائل. قد يحتفظ مزوّد الاستضافة أو الوكيل العكسي بسجلات اتصال منفصلة وفق إعداداته.
- جلسة لوحة الإدارة تنتهي بعد 8 ساعات، وتُحفظ الجلسات في الذاكرة فقط؛ إعادة تشغيل الخادم تُنهيها.
- كلمة مرور الإدارة لا تُحفظ في ملفات المشروع؛ يشتق الخادم قيمة تحقق منها باستخدام `scrypt` عند بدء التشغيل. استخدم متغير البيئة `ADMIN_PASSWORD`، ولا تضع كلمة المرور داخل ملفات عامة أو تشاركها.
- نموذج الإرسال يطلب إقرارًا واضحًا قبل الحفظ. لا تستخدمه لجمع معلومات حساسة أو رسائل دون علم مرسلها.
- إجابات مساحة التأمل الذاتي محلية في المتصفح فقط، ولا تُرسل أو تُخزن.
